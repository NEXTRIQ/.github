## NEXTRIQ

Software studio from Rotterdam, the Netherlands. We build websites, internal tools and automation for small and
medium-sized businesses. Everything runs on infrastructure the client owns, with data kept in the EU.

**What we build**

- Fast marketing sites and lead flows, from static HTML at the edge to typed forms and EU-hosted storage
- Product configurators in the browser, including interactive 3D
- Back-office automation: mail, invoices, CRM, scheduled jobs that report their own health
- AI agents where they earn their place, with deterministic rules where they don't

**How we work**

- Small, boring, well-tested building blocks over large frameworks
- Safe by default: allowlists, at-most-once side effects, dry-run before go-live
- Monitor outcomes, not exit codes
- Privacy first: no personal data in logs, minimal data at rest

**Stack we reach for**

TypeScript, Node.js, Astro, Cloudflare Workers / Pages / D1 / R2, PostgreSQL, three.js, systemd on plain Linux.

**Open source**

| Repository | What it does |
|---|---|
| [exact-forwarder](https://github.com/NEXTRIQ/exact-forwarder) | Forwards supplier invoices from Gmail to Exact Online. Deterministic rules, SPF/DKIM checks, never twice. |
| [staleguard](https://github.com/NEXTRIQ/staleguard) | Alerts when scheduled jobs stop succeeding, based on freshness instead of exit codes. Zero dependencies. |
